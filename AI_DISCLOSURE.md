# AI use disclosure

## Godot Enhanced Input (0.1.0 onwards)

Godot Enhanced Input is directed and maintained by CapsaicinBunny. Its 0.1.0 redesign — the design
document, the runtime and resource code, the modifiers and triggers, the test suite, the demo and the
documentation — was written with substantial help from an AI coding assistant (Claude, by Anthropic),
working under the maintainer's direction and decisions (name, versioning, API break, scope) and
reviewed by the maintainer.

The behaviour was specified from publicly documented behaviour of established action-based input
systems and written from scratch for this plugin; no engine source code was copied, translated or
adapted.
